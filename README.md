# Button Control with Pull-down Resistor 🔌

This project demonstrates a basic digital input application using a **Pull-down resistor** configuration. 

Bu proje, bir **Pull-down direnci** yapılandırması kullanarak temel bir dijital giriş uygulamasını gösterir.

### 🛠 How it Works / Nasıl Çalışır?
- **Logic:** In a Pull-down circuit, the input pin is connected to GND through a resistor. When the button is pressed, the signal changes from LOW to HIGH.
- **Mantık:** Pull-down devresinde, giriş pini bir direnç üzerinden GND'ye bağlıdır. Butona basıldığında sinyal LOW'dan HIGH'a döner.

### 📍 Pinout / Pin Bağlantıları
- **Pin 9:** LED (Output / Çıkış)
- **Pin 10:** Push Button (Input / Giriş)
- **Resistor:** 10k Ohm for Pull-down, 220 Ohm for LED.
